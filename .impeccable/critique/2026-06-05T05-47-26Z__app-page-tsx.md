## Priority Issues

**[P1] Silent wrong result when end meter < start meter**
- Why it matters: Start=5200, end=5100 → "Tiêu thụ: 0" → bills ₫0 for electricity silently. Financial accuracy failure.
- Fix: Inline validation when end < start; warning text on Tiêu thụ field; block or warn on invoice generation.
- Suggested command: /impeccable harden

**[P1] No room context in section headers**
- Why it matters: 14 rooms, user can lose track which room is active after scrolling. Section headers say "Tiền điện" with no room ID.
- Fix: Add active room ID to h1 or section titles. Or persistent sticky room indicator.
- Suggested command: /impeccable clarify

**[P2] RoomPriceSection layout is broken**
- Why it matters: Single input in a 4-column grid occupies 25% of the row; 75% empty. Redundant subtotal mirrors input value.
- Fix: Remove grid wrapper, render input full-width. Remove redundant subtotal row.
- Suggested command: /impeccable layout

**[P2] All state is in-memory — refresh loses all entered values**
- Why it matters: No localStorage persistence. Monthly-use tool where data entry is interrupted = recurring data loss.
- Fix: Add zustand/middleware persist with localStorage.
- Suggested command: /impeccable harden

**[P2] Blue gradient background is the first anti-reference**
- Why it matters: bg-gradient-to-b from-blue-50 to-white is the exact "Generic SaaS blue" the user named as off-limits.
- Fix: Replace with solid neutral. Pick a brand accent that isn't default Tailwind blue.
- Suggested command: /impeccable colorize
